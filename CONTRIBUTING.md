# Contributing

Thanks for helping build PDF Compressor.

## Scope

The first release focuses on local PDF compression.

Please keep issues and pull requests aligned with:

- local web app compression flow
- shared compression core
- CLI support for agents and automation
- privacy, security, and license clarity

Desktop packaging, OCR, signing, editing, splitting, merging, and cloud features are deferred.

## Development

```bash
npm install
npm test
npm run typecheck
npm run build
```

## Test Fixtures

Use synthetic or explicitly redistributable PDFs only. Do not commit private documents.
